## 3. Discrepancias Identificadas

1. **Discrepancia de Nombres de Campos:**
   - En el backend y en la base de datos se utiliza `es_activo` (en lugar de `activo`).
   - Se utiliza `fecha_creacion` y `fecha_actualizacion` (en lugar de nombres con sufijo `_especie`).
2. **Restricción de Dígitos en UI:**
   - El componente de cliente `EspeciesModal.tsx` restringe el nombre con `NOMBRE_REGEX = /^[a-zA-ZáéíóúñÁÉÍÓÚÑ\s]+$/` ("Solo letras y espacios"), impidiendo números (motivo por el cual el dato de prueba se adaptó de `"Gallina QA2"` a `"Gallina QA"`).
   - El RF-15 v1.1 prohíbe símbolos especiales pero no restringe números explícitamente.
3. **Ausencia de `grupo_manejo` en UI y Backend:**
   - La UI no tiene el control (CP-03 FALLA).
   - El backend ignora y no persiste el grupo de manejo (NW-03 FALLA, NW-04 FALLA).
